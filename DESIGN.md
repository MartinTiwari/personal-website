# Existing visual identity

This records the live site's established identity, not a new theme.

Fraunces is the display face and Caveat is the handwritten voice. Warm cream paper, dark ink, vermilion links, ochre work folders, muted blue music objects and green guestbook covers belong to the current site. Preserve these user approved choices.

Real personal photographs and Martin's existing portrait cutout carry identity. HARU is the existing ginger cat. Do not replace real people with generated portraits, invent company logos or introduce stock imagery.

Navigation uses objects with readable text and ordinary hash links. Inner pages open in the existing accessible dialog. The handwriting intro is a separate established surface and is outside the landing layout redesign.

Use soft offset shadows sparingly for paper depth, clear ink contrast, visible keyboard focus and controls at least 44 pixels high. Avoid new dependencies, continuous decorative motion, background filters and eager loading of hidden media. Respect reduced motion.

The landing layout is being reconsidered. Generated compositions are previews only until the user approves one; they must not be added to the live page as flattened screenshots.
